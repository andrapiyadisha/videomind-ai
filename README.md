# videomind-ai
VideoMind AI – Intelligent YouTube Knowledge Assistant Built a Retrieval-Augmented Generation (RAG) application using LangChain, FAISS, Hugging Face Embeddings, Groq openai/gpt-oss-120b, and Streamlit. The system extracts YouTube transcripts, performs semantic search, and answers user questions with context-aware responses and source citations.

Project: https://videomind-ai-eejdrbv6rbwydndqy7t4ze.streamlit.app/
